Rozklad 2.0.0 - wiele miast (Warszawa, Gdansk, Krakow, Boston)

Co nowego:
- Miasto i przystanki wybiera sie teraz W APLIKACJI (Wczytaj -> Wybierz miasto i przystanki),
  bez strony w Safari. Nowe ekrany: RZCitiesController.m, RZStopSearchController.m.
- Dane miast buduje GitHub Actions (tools/build_all.py + tools/miasta.json). Surowe pliki GTFS sa
  pobierane tylko na czas budowania, na strone trafiaja male pliki (index.json, d/...).
  Warszawa jest w katalogu glownym strony (zgodnosc ze starymi wersjami), reszta w podfolderach.
- Jedno miasto na raz: wczytanie innego zastepuje poprzednie dane.

Jak wgrac:
1. Wgraj CALA zawartosc do repozytorium slam0/Rozklad (razem z folderem .github i .gitignore).
2. Actions -> "Zbuduj aplikacje" -> Run workflow, potem "Strona" (strona.yml), jesli sie sama nie uruchomi.
3. W logu "Strona" zobacz, ktore miasta sie zbudowaly (miasta pominiete pisze jako "POMIJAM").
   Sprawdz tez rozmiar strony (limit GitHub Pages ok. 1 GB).

  zbudowanie zrobi dopiero GitHub Actions - jesli ktores miasto wyjdzie zle, napisz co pokazuje log.
